📋 Project idea

User:

Login to the system (login)
Sees menu
Orders products
The program calculates total
Checks discount
Checks delivery
Shows final receipt
🧠 REQUIREMENTS
🔐 PART 1 — LOGIN SYSTEM
Create:
saved_username
saved_password
Use:
login()

for:

username
password
If login is incorrect:
Access denied!
If the login is successful:
Successful login!
🍔 PART 2 — RESTAURANT MENU

Create at least:

3 products

Each product should have:

name
price
quantity
🧮 PART 3 — CALCULATIONS

Calculate:

total1
total2
total3
total_total
🎁 PART 4 ​​— DISCOUNT SYSTEM

👉 If the total is over 50€:

discount = 10

otherwise:

discount = 0
🚚 PART 5 — DELIVERY

Create:

is_delivery = True
delivery_price = 5
🧠 If there is delivery:

add delivery to the final amount.

(for now you can add it directly)

🖥️ PART 6 — FINAL RESULT

The program should display something like this:

--- FOOD PALACE ---
